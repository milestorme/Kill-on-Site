KillOnSight - Avantgarde font support

To use the "Avantgarde" font option, place your legally-licensed font file here:

  Interface\AddOns\KillOnSight\Media\Fonts\Avantgarde.ttf

Notes:
- Use a .ttf file (recommended for Classic clients).
- The addon will automatically show "Avantgarde" in the Nearby name font dropdown.
